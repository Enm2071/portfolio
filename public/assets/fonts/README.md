# Fonts

## “Astro pixel” (FontStruct)

The FontStruct license for “Astro pixel” includes a **“NO USE AS A WEBFONT”** clause (Section 2.6), which means you should **not** host/serve it from this website via `@font-face`.

If you want to use that font on a public website, you’ll need explicit permission from the font designer (or a different license).

## Current pixel display font used

This project uses a web-usable pixel font for headings via Google Fonts:

- `Press Start 2P`

Configured in `src/layouts/Layout.astro` via `--font-display` and used for key headings/brand.
